# 远期目标：导入报告后的 2D 平面电路图

## 背景

当前流程已经支持导入 Multisim 网表和交叉引用报告，并将其解析为元件、网络和引脚连接关系。后续希望在不打开 Multisim 的情况下，直接在工具内查看一张 2D 平面电路图，用于快速理解电路结构和检查连接。

## 目标

- 导入网表和交叉引用报告后，自动生成可浏览的 2D 连接图。
- 图中展示元件、引脚、网络名以及元件之间的连接关系。
- 支持点击元件或网络后，与 3D 洞洞板视图联动高亮。
- 支持按网络、元件类别、电源网络过滤显示。
- 支持缩放、拖拽、框选和自动布局。

## 非目标

- 短期内不追求还原 Multisim 原理图的视觉布局。
- 不实现完整原理图编辑器。
- 不把 2D 图作为布线算法的唯一数据源，仍以解析后的结构化网表为准。

## 初步实现思路

1. 将解析后的 `ImportState.nets` 和 `ImportState.components` 转换为图结构。
2. 节点使用元件，边使用网络；多引脚网络可生成网络节点，避免多对多连线过乱。
3. 使用自动布局算法生成初始 2D 位置。
4. 在 2D 图和 3D 视图之间共享选中状态：
   - 点击 2D 元件，高亮 3D 中该元件参与网络的所有端点。
   - 点击 2D 网络，高亮 3D 中该网络所有端点。
   - 点击 3D 元件，2D 图同步选中对应元件。

## 风险和待定点

- 大型网表的自动布局可能会很拥挤，需要分层、折叠或搜索过滤。
- 电源网络和地网络连接点很多，默认全显示可能影响可读性。
- 交叉引用报告中的逻辑引脚到物理引脚映射需要保持准确，否则 2D 图会误导用户。

## 优先级

这是远期目标。当前优先级低于导入解析准确性、元件放置、底面布线、DRC 检查和 3D 交互高亮。
