# 换封装 / 引脚编号测试电路

5 个 KiCad S-expression 网表，直接拖进 Import，点“生成元件”后即可在 3D 板上右键元件测试“使用元件库封装”。

| 文件 | 电路 | 适合测试 |
|---|---|---|
| `01-relay-driver.net` | 5V 继电器驱动 | K1 5 脚继电器；Q1 TO-92 三极管 |
| `02-bridge-pot.net` | 整流桥 + 电位器 | BR1 4 脚桥堆；RV1 3 脚电位器 |
| `03-dip14-opamp.net` | DIP-14 运放 | U1 14 脚 DIP |
| `04-to92-transistors.net` | TO-92 三极管阵列 | Q1/Q2 3 脚；Q3 被识别成 TO-220，可换回 TO-92 |
| `05-mixed-packages.net` | 继电器 + 桥 + 电位器 + DIP-8 | 5/4/3/8 脚混合 |

## 测试步骤

1. 导入一个 `.net`；
2. 点“生成元件”，元件会出现在板上；
3. 右键一个**网表生成的**元件 → “使用元件库封装…”；
4. 选择同脚数的封装；
5. 在弹窗里旋转真实模型，点引脚，点 1/2/3… 改编号，保存；
6. 回到板上确认模型已变、引脚编号与封装一致。

## 建议先试

- `02-bridge-pot.net`：BR1 4 脚，在“整流桥”和“轻触按键”之间换；RV1 3 脚，在电位器、TO-92、TO-220 之间换。
- `04-to92-transistors.net`：Q3 本来是 TO-220 的三脚 FET，右键换成 TO-92，验证“认错封装”能被改回来。
- `03-dip14-opamp.net`：U1 14 脚，测试 DIP 系列的脚号编号。
- `05-mixed-packages.net`：U1 是 DIP-8，可和 8 脚继电器互换，验证 8 脚封装的编号。

这些网表用的是物理引脚号，所以不需要 Multisim 的逻辑脚映射；换封装后引脚编号就是封装自己的 1..N。
