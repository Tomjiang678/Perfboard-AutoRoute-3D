# 换封装测试：故意认错的封装

这 5 个 KiCad 网表里的器件**故意用错 libsource 类别**，所以导入后会被放成明显错误的封装。右键它们 → “使用元件库封装…” → 选正确封装 → 编号，才能验证换封装是不是真的生效。

| 文件 | 电路 | 故意认错的元件 | 现在的封装 | 应该换成 |
|---|---|---|---|---|
| `01-relay-wrong-header.net` | 继电器驱动 | K1 `G5V-1`，类别写成 Connector | 5 脚排针 | 5 脚继电器 |
| | | Q1 `S8050`，类别写成运放 | DIP-3 | TO-92 |
| `02-pot-wrong-resistor.net` | 电位器分压 | RV1 `PT10-10K`，类别写成 Device:R | 3 脚电阻 | 3 脚电位器 |
| | | U1 `S8050`，类别写成运放 | DIP-3 | TO-92 |
| `03-bridge-wrong-diode.net` | 整流桥 | BR1 `KBU4M`，类别写成 Device:D | 4 脚二极管 | 4 脚整流桥 |
| | | RV1 `PT10-10K` | 3 脚电阻 | 电位器 |
| `04-transistor-wrong-dip.net` | 三极管阵列 | U1 `S8050` | DIP-3 | TO-92 |
| | | U2 `BC547` | 3 脚排针 | TO-92 |
| | | K1 `G5V-1` | 5 脚排针 | 继电器 |
| `05-mixed-wrong.net` | 混合 | K1 `G5V-1` | 5 脚排针 | 继电器 |
| | | BR1 `KBU4M` | 4 脚二极管 | 整流桥 |
| | | RV1 `PT10-10K` | 3 脚电阻 | 电位器 |
| | | U1 `OPA2134` | 8 脚排针 | DIP-8 或 8 脚继电器 |
| | | Q1 `S8050` | DIP-3 | TO-92 |

J1 本来就是排针，不用管。

## 测试步骤

1. 导入一个 `.net`，点“生成元件”；
2. 右键表里的错误元件 → “使用元件库封装…”；
3. 选表里“应该换成”的封装；
4. 旋转模型，点脚改 1/2/3…，保存；
5. 确认板上模型从排针/错误 DIP 变成了正确封装。

这些文件已验证：解析 0 warnings，元件会按错误封装直接生成到板上，不会卡在待补。`04` 的 Q1/Q2 和 `05` 的 U1 尤其适合看“认错封装后能不能改回来”。
