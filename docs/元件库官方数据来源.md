## 封装说明

- `OP07J` 的历史军品资料将 J 封装定义为 8 引脚金属罐（TO-99）。当前程序尚无独立 TO-99 参数化几何，因此先以 8 引脚双列几何参与放置和布线；物理引脚号已经按官方数据写入。制作实物前应使用 TO-99 转 DIP 插座，或在加入 TO-99 圆形孔位模型后再直接落板。
- `LM317AH` 是 H03A/TO-39 金属罐版本，不应套用 TO-220 版 LM317 的引脚视图；库中已将两种封装拆成独立匹配规则。
- TO-92 晶体管并不存在对所有型号都成立的统一 C/B/E 顺序。2N3904 和 2N3906 使用上面的具体型号规则；未知 BJT 仍应继续显示为待核验数据，不应从外形推断。
